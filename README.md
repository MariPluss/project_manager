# Project Manager — Django REST API

## Описание проекта

Учебный проект системы управления проектами на Django и Django REST Framework.

Реализованы регистрация и аутентификация пользователей, разграничение доступа по ролям, управление проектами и задачами, добавление комментариев и REST API.

## Роли пользователей

**Администратор (admin)**
- Просмотр, создание, редактирование и удаление проектов.
- Управление задачами.
- Управление пользователями и их ролями через Django Admin.

**Менеджер (manager)**
- Просмотр проектов.
- Создание и редактирование задач.
- Назначение исполнителей.
- Нет прав на удаление проектов и управление пользователями.

**Пользователь (user)**
- Просмотр проектов и задач.
- Добавление комментариев к задачам.
- Завершение назначенных ему задач.
- Нет прав на создание и удаление проектов и задач.

## Аутентификация и права доступа

- Пользовательская модель `CustomUser` с полем `role`.
- Аутентификация через Django Sessions.
- Защита страниц с помощью `login_required` и `LoginRequiredMixin`.
- Проверка ролей с помощью `user_passes_test` и `UserPassesTestMixin`.
- Кастомные разрешения Django REST Framework для API.

## REST API

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/api/projects/` | Список проектов |
| POST | `/api/projects/` | Создание проекта |
| GET | `/api/projects/<id>/` | Просмотр проекта |
| PUT/PATCH | `/api/projects/<id>/` | Изменение проекта |
| DELETE | `/api/projects/<id>/` | Удаление проекта |
| GET | `/api/projects/tasks/` | Список задач |
| POST | `/api/projects/tasks/` | Создание задачи |
| GET | `/api/projects/tasks/<id>/` | Просмотр задачи |
| PUT/PATCH | `/api/projects/tasks/<id>/` | Изменение задачи |
| DELETE | `/api/projects/tasks/<id>/` | Удаление задачи |

Доступ к операциям зависит от роли авторизованного пользователя.

## Запуск проекта

Установить зависимости Django и Django REST Framework, выполнить миграции:

```bash
python manage.py migrate
```

Запустить сервер:

```bash
python manage.py runserver
```
